# PGY 訓練課程表（CMH_PGYcourse）

畢業後一般醫學訓練（PGY）年度輪訓課程表的前端網頁。
**資料一律以 Google Sheets 為準**，前端透過 Google Apps Script（GAS）Web App 讀取，
連線失敗或尚未設定時，會自動退回內建的離線範例資料。

---

## 一、檔案結構

```
index.html                 主頁面（完整版）
office.html                辦公室版：頁首＋總覽表／月份檢視，橘色系，適合 iframe 嵌入
check.html                 GAS 連線檢測頁（串接後先開這頁確認）
assets/config.js           ★ 唯一需要修改的設定檔（GAS 網址、色票）
assets/style.css           樣式（含深色模式、列印樣式）
assets/app.js              前端主程式
assets/sample-data.js      離線範例資料（由範例 course 表轉出）
gas/Code.gs                ★ Google Apps Script 後端（貼到試算表的 Apps Script）
```

## 二、試算表格式

第 1 列為表頭，欄位名稱與範例表完全一致：

| 長期導師 | 學年度 | 組別 | 期程 | 人事號 | 簡碼 | 受訓醫師 | 2026/08 | 2026/09 | … | 2028/07 |
|---|---|---|---|---|---|---|---|---|---|---|
| 胡婷勻 | 115 | 未分 | PGY1 | B508F1 | 2204 | 陳怡蓁 | 外 | 外 | … | |

規則：

- **前 7 欄為固定欄**，順序不拘（程式以「欄位名稱」比對，不是以位置）。
- **其後為月份欄**，格式 `yyyy/mm`（日期格式或文字皆可）。
  也接受 `2026-08`、`2026年8月`、民國 `115/08`。欄數不限，可以是 12 個月或 24 個月。
- **`受訓醫師` 為空的列視為空白列**，會自動略過。
- 新增/刪除列、新增月份欄，網頁都會自動跟著變，不必改程式。

### 科別判定與顏色

**只看開頭字元**，括號或連字號後面寫什麼都不影響：

| 儲存格內容 | 判定科別 | 顏色 |
|---|---|---|
| `內`、`內科`、`內(Y2不分)`、`內(外)` | 內科 | 黃 `#FFC000` |
| `外`、`外(整外)`、`外-內` | 外科 | 綠 `#92D050` |
| `婦`、`婦(產)` | 婦產 | 粉 `#FFCCCC` |
| `兒`、`兒(新生兒)` | 兒科 | 咖啡 `#9D6201` |
| `急`、`急-內`、`急-外` | 急診 | 藍 `#00B0F0` |
| `老醫`、`老年醫學` | 老醫 | 紫 `#B287D9` |
| `兵役`、`兵` | 兵役 | 黑底白字 `#000000` |
| `選-眼科`、`選-內` | 選修 | 白 `#FFFFFF` |
| **以上都不符合**（`社-新樓`、`新樓`、`麻醉`…） | 社區 | 紅 `#FF0000` |

注意兩點：

- `急-內` 歸**急診**不是內科 —— 判定看的是開頭的「急」
- **沒有「其他」這一類**，比對不到任何前綴的一律歸社區（由 `DEFAULT_CATEGORY` 指定）。
  空白儲存格不受影響，仍視為沒有排課

色塊會自動加一圈細描邊，白色的選修在白底上、黑色的兵役在深色模式下才看得見；
描邊顏色依色塊亮度自動決定（極深的用淺色描邊，其餘用深色）。

文字顏色（深色或白色）由程式比較兩者的 WCAG 對比度後自動挑高的那個。
目前各科別的對比度：兵役 21:1、選修 15.6:1、婦產 11:1、內科 9.5:1、外科 8.5:1、
急診 6.3:1、老醫 5.5:1、兒科 5:1、**社區（紅）4:1**。

> 社區的純紅 `#FF0000` 配白字是 4:1，略低於 WCAG AA 的 4.5:1。
> 白字配紅底實務上仍清楚，若要更保險，把 `CATEGORY_COLORS` 的 `'社區'`
> 改成稍深的 `#E00000`（5.1:1）即可，看起來仍是紅色。

### 月份檢視的分組

`config.js` 的 `MONTH_GROUP_BY` 決定「月份檢視」的卡片怎麼併：

- `'unit'`（預設）依**訓練單位**分組：

  | 儲存格寫法 | 併成 |
  |---|---|
  | `內`、`內(Y2內)`、`內(Y2不分)` | 一組「內」 |
  | `婦`、`婦(Y2婦)`、`婦(完訓)` | 一組「婦」 |
  | `急`、`急-內`、`急-外`、`急-內(Y2)` | 一組「急」 |
  | `外`、`外-內`、`外(整外)` | 一組「外」 |
  | `選-眼科`、`選-眼科(Y2)` | 一組「選-眼科」 |
  | `選-眼科` vs `選-耳鼻喉` | **分開**兩組 |
  | `社-新樓` vs `社-佳里` | **分開**兩組 |
  | `社-郭綜`、`社內-郭綜`、`社外-郭綜`、`社婦-郭綜` | **分開**四組（卡片各自獨立） |

  規則是：**括號一律視為註記而去掉**；**連字號後面預設也視為註記**，
  只有列在 `KEEP_SUFFIX_CATEGORIES` 的科別例外。

  社區醫院的 `社內-`、`社外-`、`社婦-` **只在篩選按鈕上合併**，卡片仍各自獨立 ——
  見下方「月份檢視的科別篩選」。

  ```js
  KEEP_SUFFIX_CATEGORIES: ['選修', '社區'],
  ```

  選修與社區的連字號後面是實際去的單位（眼科、新樓），合併會看不出誰在哪裡，
  所以保留；其他科別（內、外、婦、兒、急、老）的後綴是註記，一律合併。

  卡片裡若某人原本的寫法與組名不同，會標在名字旁邊，資訊不會不見。
  標籤不會重複卡片標題已寫明的科別：

  | 卡片 | 儲存格內容 | 標籤 |
  |---|---|---|
  | 外 | `外(Y2不分)` | `(Y2不分)` |
  | 婦 | `婦(完訓)` | `(完訓)` |
  | 急 | `急(Y2不分)` | `(Y2不分)` |
  | 急 | `急-外`、`急-外(完訓)` | **`急-外`、`急-外(完訓)`（整串保留）** |

  判斷方式：去掉組名後若緊接著括號，那只是註記，可以省略組名；
  若緊接著連字號，代表是不同的訓練單位 —— 要看得出去急診是 run `急-外` 還是 `急-內`，
  所以整串保留。全形括號 `（）` 與全形連字號 `－` 一樣有效。

  **一張卡片裡混了多種單位時**（社-安南／社內-安南／社外-安南，或 急／急-內／急-外），
  連與卡片同名的那些也會標出來 —— 否則「沒有標籤」到底是一般社區還是漏標，讀的人分不出來。
  只有一種單位時維持原樣，不做多餘的重複。

- `'category'` 依**科別**分組，同科別全部併成一組：所有 `選-xx` → 一組「選修」，
  所有 `社-xx` → 一組「社區」。

> 這個設定不影響「總覽表」，總覽表一律顯示儲存格原文。

顏色來源由 `config.js` 的 `COLOR_SOURCE` 決定：

- `'category'`（預設）：一律依科別上色，**同科別顏色必定一致**，忽略試算表的儲存格底色
- `'sheets'`：以試算表的儲存格底色為主，沒有底色時才用預設色票

> 若試算表裡同一科別被填了不同底色（例如把某格 `選-眼科` 標成紅色提醒），
> `'sheets'` 模式會照實顯示紅色，`'category'` 模式則統一顯示選修的紫色。

要新增科別：在 `CATEGORY_COLORS` 加一組顏色，再到 `CATEGORY_RULES` 加一條前綴規則（順序由上往下比對）。

## 三、部署 GAS 後端

1. 開啟課程表 Google Sheets → **擴充功能 → Apps Script**
2. 把 `gas/Code.gs` 整份內容貼上，存檔
3. （選用）若腳本不是綁在該試算表上，把最上方的 `SPREADSHEET_ID` 填成試算表 ID
4. **部署 → 新增部署作業 → 類型選「網頁應用程式」**
   - 執行身分：**我**
   - 誰可以存取：**任何人**（若只給院內看，選「機構內的任何人」）
5. 複製「網頁應用程式」網址（`https://script.google.com/macros/s/AKfycb.../exec`）

### API

| 方法 | 參數 | 說明 |
|---|---|---|
| GET | `?action=schedule&sheet=工作表名稱` | 取得課表 JSON（`sheet` 可省略＝第一個工作表） |
| GET | `?action=sheets` | 取得所有工作表名稱 |
| GET | `?action=ping` | 健康檢查 |
| GET | 任一請求加 `&callback=fn` | 回傳 JSONP（繞過瀏覽器 CORS 限制） |
| POST | `{action:'updateCell', sheet, 簡碼, month:'2026-08', value:'外'}` | 寫回單一儲存格 |
| POST | `{action:'updateRow', sheet, 簡碼, months:{'2026-08':'外', …}}` | 寫回整列月份 |

回應格式：

```json
{
  "ok": true,
  "sheet": "11509(詩)",
  "sheets": ["11509(詩)", "11409(甲)"],
  "fixedCols": ["長期導師","學年度","組別","期程","人事號","簡碼","受訓醫師"],
  "monthCols": [{ "key":"2026-08", "label":"2026/08", "year":2026, "month":8 }],
  "rows": [{
    "長期導師":"胡婷勻", "學年度":"115", "組別":"未分", "期程":"PGY1",
    "人事號":"B508F1", "簡碼":"2204", "受訓醫師":"陳怡蓁",
    "months": { "2026-08": { "value":"外", "color":"#92d050" } }
  }],
  "updatedAt": "2026/09/07 10:00:00"
}
```

`Code.gs` 上方可調整的參數：`FIXED_COLS`、`HEADER_ROW`、`KEY_COL`、`ID_COL`、
`WRITE_TOKEN`（寫入保護權杖，留空＝不檢查）、`CACHE_SECONDS`（讀取快取秒數）。

試算表上也會多出「**PGY 課程表**」選單，可清除 API 快取與檢查表頭格式。

## 四、設定前端

編輯 `assets/config.js`：

```js
GAS_WEB_APP_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
DEFAULT_SHEET:   '',        // 留空＝第一個工作表
TRANSPORT:       'auto',    // auto：先 fetch，被 CORS 擋住自動改用 JSONP
AUTO_REFRESH_MS: 0,         // 想自動同步就設 300000（5 分鐘）
```

同一檔案也可調整 `COLOR_SOURCE`（顏色來源）、`CATEGORY_COLORS`（科別色票）
與 `CATEGORY_RULES`（值→科別的判斷前綴），詳見上方「科別判定與顏色」。

> 若 GAS 網址填錯或未授權，網頁不會壞掉，會顯示紅色提示並改用離線範例資料。

### 連線檢測

串接後打開 **`check.html`**，它會依序測：fetch（CORS）→ JSONP 備援 → `action=sheets` → `action=schedule`，
並把實際回應內容印出來。四項都通過就表示可以正常使用；有失敗時頁面下方會列出對應的排查步驟。

常見狀況：

| 症狀 | 原因 |
|---|---|
| 第 1 項失敗、第 2 項通過 | fetch 被 CORS 擋住，程式自動改走 JSONP，**屬正常，不必處理** |
| 全部失敗，訊息含「登入頁」 | 部署時「誰可以存取」不是「任何人」 |
| 全部失敗，訊息為載入失敗 | 網址錯誤，或結尾是 `/dev` 而非 `/exec` |
| 資料是舊的 | 改過 `Code.gs` 後沒有重新部署新版本；或試算表選單「PGY 課程表 → 清除 API 快取」 |

## 六、響應式版面

同一份頁面在手機、平板、桌機都不跑版，斷點與對應行為：

| 寬度 | 版面 |
|---|---|
| ≥ 900px | 七個固定欄全部黏在左側；表格有自己的捲動區，年／月表頭黏在上方 |
| 520–900px | 只黏住「受訓醫師」欄（七欄會吃掉整個畫面），其餘固定欄從它下面捲過去 |
| < 520px | 同上，另外篩選欄位改為兩欄、字級與間距縮小 |

表格一律在自己的容器內水平捲動，頁面本身不會出現水平捲軸。
月份卡片的最小寬度用 `minmax(min(310px,100%),1fr)`，
小螢幕不會被 `.view` 的 `overflow:hidden` 裁掉。

## 七、辦公室版 office.html

`office.html` 保留頁首與**總覽表／月份檢視**兩個頁籤（沒有個人時程），
不放篩選列與頁尾，適合用 `<iframe>` 嵌到其他系統或內部網頁：

```html
<iframe src="office.html" style="width:100%;height:640px;border:0"></iframe>
```

- 與 `index.html` **共用** `assets/` 底下同一份 `config.js` / `app.js` / `style.css`，
  改任何功能兩頁都會同步，不需要維護兩份程式
- `app.js` 對不存在的介面元素會安靜跳過，所以少掉的頁首與篩選列不會讓程式出錯
- 有哪些檢視由外殼的頁籤決定：`app.js` 會以 `hasView()` 檢查頁籤是否存在。
  `office.html` 沒有個人時程頁籤，總覽表的姓名就自動改為純文字而非可點連結，
  不會跳到沒有對應分頁的畫面
- 沒有篩選列，因此顯示的是**全部資料**；工作表取 `config.js` 的 `DEFAULT_SHEET`
  （留空＝試算表第一個工作表）
- 佈景沿用使用者在 `index.html` 選過的深／淺色設定（存在 `localStorage`）
- 仍保留錯誤提示區塊：正常連線時完全看不到，只有在讀不到 Google Sheets、
  退回離線範例資料時才會顯示警告 —— 少了它，使用者會把範例資料誤當成正式課表

### 月份檢視的科別篩選

`office.html` 的月份檢視在標題下方有一排**科別複選按鈕**，
讓科部助理選完月份後，直接挑自己要看的科：

- **可複選**，選了哪些科會在下方以「**已選擇**」列出
- 旁邊有「**清除篩選**」一鍵取消
- 選到的科別當月沒有人被排到時，顯示「**查無資料**」，
  並註明是哪個月、哪一科 —— 而不是一片空白讓人分不清是沒人還是壞掉
- 換月份時選擇會保留，方便一路往後看同一科

**社區醫院的按鈕以「醫院」為單位合併**（`config.js` 的 `FILTER_MERGE_PREFIX`）：

| | |
|---|---|
| 按鈕 | `社-郭綜` **一個**（不是 社-／社內-／社外-／社婦- 四個） |
| 選了之後的卡片 | `社-郭綜`、`社內-郭綜`、`社外-郭綜`、`社婦-郭綜` **各自一張** |

科部助理是以醫院為單位在找人，但看的時候要分得出各次分組，所以
**合併只發生在按鈕與比對上，卡片不合併**。選修不列入 ——
`選-眼科` 與 `選-骨科` 本來就是不同單位，按鈕也該分開。

按鈕清單 = **資料裡實際出現過的訓練單位** ∪ **`config.js` 的 `MONTH_UNIT_CHOICES`**。
併入固定清單是為了讓當月沒人的科別也選得到 —— 否則連按鈕都找不到，
就無法分辨是「沒人去」還是「漏掉了」。順序：先依科別，同科別內沿用
`MONTH_UNIT_CHOICES` 的排列，沒列到的排後面。

這個篩選列由 `office.html` 的 `<body data-unit-filter>` 啟用。
`index.html` 已有整頁的篩選列，因此不加這個屬性、也不會出現這排按鈕。

### 配色

| | index.html | office.html |
|---|---|---|
| 色系 | 玫瑰粉 `#A83459` | 蜜柑橘 `#C2410C` |
| 標誌 | 白粉漸層愛心 48×44 | 白橘漸層星星 58×55 |
| 標題列文字 | 白 | 深棕 `#4A1D00` |

**為什麼 office 的標題列用深色文字：** 鮮豔的橘色亮度高，白字最多只有 2.4:1，
連大字級的 3:1 都不到。要壓到白字達標就得暗到接近鏽紅，整條看起來死氣沉沉。
所以改走「鮮豔橘底 + 深棕文字」。

標題列是四段漸層 `#FFB347 → #FF9A3C → #FB8500 → #F26B0A`，
標題與副標對四個色階皆為 **8.04 / 6.78 / 5.77 / 4.69**，全段達 WCAG AA。
副標若用半透明，在最深端只有 3.8:1，因此改為不透明，層次改由字級與粗細區分。

色票直接覆寫在 `body.office` 上，所以整頁（含表格、分頁、連結）一起換色。
深色模式另外寫了一組 `[data-theme="dark"] body.office` ——
`[data-theme="dark"]` 定義在 `:root`，若只寫 `body.office` 的淺色版，
會因為定義在較內層而反過來蓋掉深色模式的色票。

## 八、網頁功能

| 分頁 | 內容 |
|---|---|
| **總覽表** | 完整輪訓矩陣。欄序為長期導師→學年度→期程→組別→人事號→簡碼→受訓醫師；捲動時年／月表頭與整組固定欄都會黏住（視窗寬度未達 900px 時只黏表頭）；點姓名可跳到個人時程 |
| **月份檢視** | 選定某個月，依訓練單位分組列出該月所有受訓醫師 |
| **個人時程** | 先輸入姓名或人事號查詢，再顯示該員的逐月色塊時間軸 ＋ 各科月數 |
